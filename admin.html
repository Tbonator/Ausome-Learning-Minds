Owner setup instructions
  1. First deploy this admin feature and its content file to the website's main branch.
  2. In GitHub, create a fine-grained personal access token with an expiry date. Choose only Tbonator/Ausome-Learning-Minds and give Contents: Read and write access. Keep all other optional permissions off.
  3. Enter the token here and connect to load the latest saved page. Do not share your token.
  4. Edit, preview, then choose Publish changes. The website updates after GitHub Pages finishes its deployment.

The repository's GitHub permissions protect publishing. This editor does not use a shared website password. Use it on your own trusted device and disconnect when finished.
